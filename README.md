# КАССА-ПРО

Локальный прототип кассы и браузерной админки для продуктовых и вещевых магазинов.

## Запуск кассы

```powershell
.\KASSA-PRO.bat
```

Если касса запускается второй раз, второе окно не откроется: приложение покажет сообщение, что касса уже запущена.

## Запуск админки

```powershell
.\ADMIN-KASSA-PRO.bat
```

Админка открывается в браузере:

- на этом компьютере: `http://localhost:5173/admin/`
- с телефона в той же Wi-Fi сети: адрес `http://<IP-компьютера>:5173/admin/` печатается в окне запуска

## Демо-аккаунты

- `Магазин Урожай`, ключ кассы: `UROJ-2026-0001`
- `Магазин Текстиль`, ключ кассы: `TEXT-2026-0001`

Ключ первичного входа одноразовый и теперь принадлежит конкретной кассе. Если ключ уже использован, в админке откройте раздел `Магазины`, зайдите в карточку кассы и нажмите `Сгенерировать одноразовый ключ`.

## Что работает

- привязка кассы к аккаунту, магазину и конкретной кассе по одноразовому ключу;
- вход на смену под кассиром из админки с PIN/паролем кассы;
- локальный offline-кэш товаров, категорий, цен и остатков в SQLite;
- обновление кассы из админки по кнопке `Обновить`;
- товары, категории, фото, закупочная цена, продажная цена и штрихкод;
- генерация внутреннего EAN-13 для товара без штрихкода;
- оприходование документами: черновик, добавление товаров, сохранение, проведение и история движения товара;
- продажи, отложенные чеки, история продаж, открытие и закрытие смены, отчеты по закрытым сменам в админке;
- два независимых демо-аккаунта, данные между ними не смешиваются;
- PWA-баннер админки для установки на телефон.

Прототип не является фискальной кассой и пока не подключает реальные принтеры, терминалы, весы или ОФД.
